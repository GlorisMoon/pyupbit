# 주간 브리핑 메일 초안

1. 플러그인 루트(이 파일에서 두 단계 위)에서 메일 본문을 만듭니다.
   ```bash
   python3 scripts/build.py all --email
   ```
   `out/email.html`(HTML 본문)과 `out/email.txt`(일반 텍스트 대체본)가 생깁니다.
2. `data/config.json`의 `email.subjectPrefix` 뒤에 오늘 날짜를 붙여 제목을 만듭니다.
   예: `[주간] AI·양자·로봇 테마 브리핑 2026-10-12`
3. Gmail `create_draft`를 호출합니다.
   - `to`: 이 세션의 계정 소유자 본인 이메일 (세션 컨텍스트에 있는 사용자 이메일). 다른 수신자는 사용자가 지정했을 때만 추가합니다.
   - `subject`: 위에서 만든 제목
   - `htmlBody`: `out/email.html` 전체 내용
   - `body`: `out/email.txt` 전체 내용
4. 응답의 `viewUrl`을 사용자에게 알려 줍니다. 메일은 절대 직접 발송하지 않습니다.

## 주의
- 이메일 주소를 저장소 파일에 적지 않습니다.
- 본문의 아티팩트 링크는 비공개입니다. 받는 사람이 열려면 사용자가 아티팩트 공유 메뉴에서 공유해야 한다는 문장이 본문 하단에 이미 들어 있습니다.
- Gmail 커넥터가 연결되지 않았으면 초안을 만들 수 없다고 알리고, `out/email.html` 경로를 대신 안내합니다.
